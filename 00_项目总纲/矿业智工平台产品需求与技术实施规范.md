# 2. 产品定位

## 2.1 产品定义

矿业智工平台是面向采矿、选矿、矿山自动化、电气、设备仪表及相关工程专业的在线工具、知识学习、动态仿真、项目管理和企业协作平台。

第一阶段聚焦：

> 选矿工程在线工具＋专业知识工作台。

第二阶段扩展：

- 采矿工程
- 矿山自动化
- 矿山电气
- 尾矿与充填
- 企业知识库
- 现场数据分析

## 2.2 核心价值

平台必须同时具备：

1. **能计算**：解决高频工程计算。
2. **能分析**：提供物料、金属、动力学和高级分析。
3. **能学习**：将知识、设备、仪表和案例结构化。
4. **能设计**：生成清单、控制策略和工程成果。
5. **能管理**：保存项目、版本和团队协作。
6. **能持续更新**：持续发布行业痛点工具和资料。

## 2.3 产品差异化

```text
普通资料网站：主要解决“查资料”
单一计算器：主要解决“算一个数”
大型商业软件：功能强但成本高、学习复杂
通用AI：知识广但行业过程和工程边界不足

矿业智工平台：
资料＋工具＋动态流程＋高级分析＋项目成果＋AI
```

# 4. 核心用户场景

## 4.1 基础计算场景

```text
进入工具中心
→ 搜索“干固体量”
→ 输入流量、密度和浓度
→ 查看结果和计算过程
→ 保存到项目
→ 导出计算记录
```

## 4.2 动态流程学习场景

```text
选择磨矿分级路线
→ 查看设备和物流
→ 点击旋流器压力控制
→ 查看PV/SP/MV
→ 调整PID参数
→ 查看趋势变化
→ 打开仪表资料
```

## 4.3 工程设计辅助场景

```text
创建项目
→ 输入项目参数
→ 选择工艺路线
→ 生成设备清单
→ 生成仪表清单
→ 生成I/O清单
→ 生成控制策略
→ 导出Word和Excel
```

## 4.4 高级分析场景

```text
上传历史数据
→ 校验数据质量
→ 运行高级分析
→ 查看拟合和诊断
→ 对比参数方案
→ 保存到项目
→ 生成分析报告
```

## 4.5 企业协作场景

```text
企业管理员创建项目
→ 分配团队成员
→ 工艺工程师填写参数
→ 自动化工程师补充控制
→ 审核员审查
→ 形成版本
→ 导出正式成果
```

# 9. 网页设计系统规范

## 9.1 设计目标

视觉设计与功能开发同级验收。

设计应达到：

- 专业
- 现代
- 克制
- 高效
- 清晰
- 具有矿业行业辨识度
- 适合长时间工程使用

不采用：

- 大量无意义渐变
- 过多发光边框
- 过度游戏化
- 密集堆叠小字体
- 大面积纯黑
- 强烈闪烁
- 功能按钮颜色混乱

## 9.2 主题

### 深色工程主题

适用于：

- 动态工艺
- PID趋势
- 高级分析
- 项目工作台
- 设备状态

建议色彩方向：

- 页面背景：深蓝黑
- 主面板：深灰蓝
- 次面板：略亮灰蓝
- 主色：青蓝或矿业蓝
- 辅助色：铜金、矿石棕
- 正常：绿色
- 警告：橙色
- 危险：红色
- 信息：蓝色
- 禁用：低饱和灰

### 浅色阅读主题

适用于：

- 知识文章
- 报告预览
- 表格打印
- 公开内容页

## 9.10 动效规范

动效只用于说明状态和因果关系。

时间建议：

- hover：120～180ms
- 面板展开：180～260ms
- 页面过渡：220～320ms
- 状态变化：自然、连续
- 报警闪烁：低频，支持关闭

必须支持系统“减少动态效果”设置。

# 28. 结论

矿业智工平台第一阶段的关键不是把所有桌面功能搬上网页，而是建立一个高质量、可持续、可收费、可扩展的产品基础。

第一阶段必须同时做好三件事：

```text
专业工具真正有用
＋
网页界面真正好看
＋
技术架构能够持续扩展
```

平台的长期竞争力来自：

- 专业工程核心
- 工具和知识联动
- 动态工艺与高级分析
- 项目成果输出
- 持续更新机制
- 企业数据与协作能力
