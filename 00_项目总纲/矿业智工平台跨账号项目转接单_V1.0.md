## 一、转接说明

本转接单用于把“矿业智工平台”从当前ChatGPT账号转交到另一个ChatGPT账号继续建设。

跨账号转接时，另一个账号通常不会自动继承：

- 当前账号的历史对话；
- 已确认的产品决策；
- 已生成但未复制到本地的文件；
- 本地工程目录；
- 数据库；
- Logo原始资源；
- 版本包与校验文件；
- 服务器、域名和密钥；
- 已形成的开发习惯与验收口径。

因此，另一个账号开始工作前，必须先阅读本转接单，并核对项目文件、数据库、文档和版本状态。

# 1. 项目最终目标

## 1.1 平台定位

矿业智工平台的最终目标是：

> 打造国内一流的专业矿业工程在线工具和知识工作台。

平台面向的主要专业方向包括：

- 选矿工程；
- 采矿工程；
- 自动化；
- 电气工程；
- 设备工程；
- 土建工程；
- 工程项目管理；
- 矿业工程知识与资料服务。

“选矿工程师工具箱”不是整个平台，而是矿业智工平台中的一个重要工具集和能力来源。

## 1.2 核心价值

平台应持续解决矿业工程行业中的实际痛点：

```text
工程计算效率低
＋
公式和单位容易出错
＋
专业资料分散
＋
软件工具碎片化
＋
设计过程难以复用
＋
项目数据难以沉淀
＋
经验难以标准化
＋
跨专业协作困难
```

平台最终应形成：

```text
在线工程工具
＋
专业知识库
＋
项目工作台
＋
计算历史
＋
工程数据复用
＋
团队协作
＋
AI工程助手
＋
会员与企业服务
```

## 1.3 产品形态

平台规划为网页化综合产品，主要产品区域包括：

1. 官网和品牌首页；
2. 工具中心；
3. 工具详情页；
4. 项目工作台；
5. 统一计算历史；
6. 专业知识库；
7. 设备资料库；
8. 选矿工程师工具箱网页版本；
9. 自动化方案生成；
10. AI工程助手；
11. 团队协作；
12. 会员、订阅与企业服务；
13. 后续开放API和私有化部署。

## 1.4 质量目标

平台必须同时满足：

- 专业正确；
- 计算可追溯；
- 数据可复用；
- 权限可审计；
- 界面美观；
- 使用简单；
- 响应式良好；
- 后续可扩展；
- 可进行商业化；
- 可部署到正式生产环境。

网页界面质量与专业内容同等重要，不允许把平台做成粗糙的普通后台模板。

```text
App Router
Typed Routes
CSS Modules
Storybook

```

主要原则：

- TypeScript严格模式；
- 不允许隐式`any`；
- 启用Typed Routes；
- 页面与通用组件分层；
- 工程公式不写在前端；
- 组件必须有Story和测试；

# 6. 已确认的重要产品决策

## 6.1 平台不是单一工具

矿业智工平台是综合性专业平台。

“选矿工程师工具箱”是平台中的一个板块或工具集合，不是平台全部。

## 6.2 先建立通用底座，再批量开发工具

已确认开发顺序：

```text
品牌
→ UI系统
→ 组件库
→ 工具中心
→ 正式工具
→ 项目和历史
→ 用户和团队
→ 会员和配额
→ 数据库和生产部署
→ 批量扩充专业工具
```

不允许为赶进度而跳过通用底座，重复编写页面。

## 6.3 页面美观与内容同等重要

网页不能做成：

- 深黑色普通后台；
- 低质量表单堆砌；
- 无品牌识别；
- 第三方组件默认风格；
- 信息拥挤；
- 不适合工程师长时间使用的界面。

当前默认视觉方向：

- 浅色为主；
- 青绿和蓝色品牌色；
- 大量留白；
- 轻量边框；
- 克制阴影；
- 统一圆角；
- 工程数据清晰；
- 桌面优先，同时支持移动端。

## 6.4 工程计算必须可追溯

每个正式工具必须返回：

- 原始输入；
- 标准单位输入；
- 公式；
- 代入过程；
- 中间结果；
- 最终结果；
- 单位；
- 工程警告；
- 数据有效性；
- 假设与边界；
- 公式版本；
- 工具版本；
- request_id。

## 6.5 `0`不是空值

全平台统一规则：

```text
0 → 有效数值
null → 无数据
NaN → 计算错误
```

不得使用类似：

```ts
value || "--"
```

导致0被错误显示为无数据。

## 6.6 权限由服务端最终决定

前端`PermissionGate`只负责展示。

正式授权链：

```text
用户
→ 团队
→ 角色
→ 项目权限
→ 套餐
→ 功能权益
→ 配额
→ FastAPI最终校验
```

不能只隐藏前端按钮。

## 6.7 数据复用必须显式映射

跨工具复用不能根据字段同名自动猜测。

必须定义：

- 来源工具；
- 来源字段；
- 来源单位；
- 目标工具；
- 目标字段；
- 目标单位；
- 转换规则；
- 无法映射字段；
- 复用警告。

## 6.8 本地与生产环境必须分离

本地可以使用：

- SQLite；
- 本地开发密码；
- 模拟支付；
- 非Secure Cookie；
- Docker开发Compose。

生产必须使用：

- PostgreSQL；
- Secure Cookie；
- 禁用Bearer；
- 禁用模拟支付；
- Alembic；
- 正式TLS；
- secrets；
- 备份；

## 6.9 会员策略

基础工具可免费使用，高阶能力进入：
