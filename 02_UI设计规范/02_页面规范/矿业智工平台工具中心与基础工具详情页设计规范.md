# 1. 文档目的

本规范用于统一矿业智工平台“工具中心”和“基础工具详情页”的产品结构、页面布局、交互逻辑、视觉标准、数据结构、权限控制、响应式设计、测试与验收标准。

本规范重点解决以下问题：

1. 用户如何快速找到所需工具；
2. 工具数量增加后如何分类、筛选和排序；
3. 免费工具与专业会员工具如何清晰区分；
4. 工具审核状态、版本和适用范围如何展示；
5. 所有计算工具如何使用统一页面模板；
6. 输入、计算、结果、过程、保存与导出如何形成完整闭环；
7. 工具如何与项目、知识、AI助手和会员体系联动；
8. 如何保证页面既专业、清晰，又具备良好视觉品质；
9. 如何避免后续每增加一个工具都重复设计和重复开发；
10. 如何保证专业、功能、视觉三重验收。

本规范是后续以下工作的直接依据：

- 工具中心高保真设计；
- 干固体量计算页高保真设计；
- UI基础组件库V0.1；
- Next.js前端实现；
- FastAPI计算接口；
- 工具配置中心；
- 会员权益判断；
- 自动测试与视觉回归测试。

# 2. 设计目标

## 2.1 产品目标

工具中心必须成为平台最重要的高频入口之一。

用户进入后，应能在较短时间内完成：

```text
找到工具
→ 理解用途
→ 判断是否适用
→ 输入参数
→ 获得结果
→ 查看过程
→ 保存到项目
→ 导出成果
```

## 2.2 视觉目标

整体视觉必须符合：

```text
专业工程软件的严谨
＋
现代SaaS产品的整洁
＋
矿业行业的专业辨识度
```

页面不能表现为：

- 传统后台管理系统；
- 普通在线计算器；
- 新闻门户式工具列表；
- 大量相同卡片的机械堆叠；
- 过度科技感和高亮霓虹；
- 深色背景覆盖全部工具页面；
- 大面积空白导致信息密度过低。

## 2.3 体验目标

用户应感受到：

- 工具容易找；
- 输入容易懂；
- 单位不会混；
- 结果可信；
- 公式可追溯；
- 错误可定位；
- 数据可保存；
- 会员边界清楚；
- 页面长时间使用不疲劳。

# 3. 适用范围

本规范第一阶段适用于：

- 选矿基础计算工具；
- 浆体计算工具；
- 金属量与回收率工具；
- 磨矿分级基础工具；
- 药剂制度换算工具；
- 泵、电机和能耗基础工具；
- 后续自动化、电气、采矿基础计算工具。

第一阶段不直接适用于：

- 大型流程建模器；
- 动态工艺仿真；
- 多节点物料平衡编辑器；
- 高级动力学拟合；
- 多文件数据协调；
- 实时生产数据看板；
- 复杂报告编辑器。

上述复杂功能应在统一工具体系下使用专门页面模板。

# 4. 用户角色与需求

## 4.1 游客

主要需求：

- 快速体验；
- 判断平台是否专业；
- 使用少量基础工具；
- 查看工具说明和示例。

限制：

- 不能保存云项目；
- 不能查看完整历史；
- 部分导出受限；
- AI额度受限。

## 4.2 免费用户

主要需求：

- 使用全部免费工具；
- 保存有限数量计算记录；
- 创建有限数量项目；
- 收藏工具；
- 查看历史；
- 使用有限AI辅助。

## 4.3 专业会员

主要需求：

- 使用全部专业工具；
- 高级参数；
- 批量计算；
- 报告导出；
- 更多项目；
- 计算方案保存；
- 项目参数复用；
- 高级AI分析。

## 4.4 团队与企业用户

主要需求：

- 企业工具模板；
- 企业默认参数；
- 项目共享；
- 统一单位；
- 审核；
- 版本；
- 审计；
- 企业知识联动。

## 4.5 专业审核人员

主要需求：

- 查看工具公式；
- 查看单位；
- 查看边界条件；
- 查看测试样例；
- 审核版本；
- 标记风险；
- 发布审核状态。

# 7. 工具中心内容分区

## 7.1 推荐工具

依据：

- 用户专业；
- 最近使用；
- 当前项目；
- 收藏；
- 会员权益；
- 平台推荐。

推荐数量：

- 桌面端4～6个；
- 手机端2～4个。

## 7.2 最近使用

登录用户显示。

字段：

- 工具名称；
- 上次使用时间；
- 上次项目；
- 上次结果摘要；
- 继续计算。

## 7.3 收藏工具

登录用户显示。

支持：

- 拖动排序；
- 取消收藏；
- 固定到工作台；
- 按项目收藏。

## 7.4 热门工具

显示真实统计，不使用虚构数据。

可显示：

- 使用次数；
- 最近7天增长；
- 收藏数；
- 工具评分。

平台未上线前，只显示“首批推荐”，不显示虚构数字。

## 7.5 全部工具

支持：

- 卡片视图；
- 紧凑列表视图；
- 视图偏好保存。

## 8.1 卡片内容

工具卡片必须显示：

1. 工具图标；
2. 工具名称；

6. 审核状态；
7. 使用入口；
8. 收藏入口；
9. 最近更新时间；
10. 可选的使用次数或最近使用状态。

## 8.2 卡片层级

推荐结构：

```text
顶部
├─ 图标
├─ 专业标签
└─ 权益标签

中部
├─ 工具名称
└─ 一句话说明

底部
├─ 审核状态
├─ 更新时间
└─ 使用按钮
```

## 8.3 卡片状态

必须设计：

- 默认；
- hover；
- focus；
- 已收藏；
- 最近使用；
- 新增；
- 会员锁定；
- 审核中；
- 已停用。

## 8.4 卡片尺寸

桌面卡片建议：

- 宽度：最小260px；
- 高度：210～240px；
- 内边距：20～24px；
- 圆角：16～18px；
- 卡片间距：16～20px。

1366px页面：

- 3列或4列；
- 根据容器宽度自适应。

1920px页面：

- 4列或5列；
- 不无限拉宽卡片。

## 8.5 会员卡片

专业工具不能只显示锁图标。

应明确显示：

- 专业会员；
- 核心价值；
- 可预览内容；
- 升级入口；
- 当前权益。

免费用户可进入详情页查看用途、输入和部分示例，但执行高级计算前由后端校验权限。

# 11. 输入面板规范

## 11.1 每个输入项必须包含

- 中文名称；
- 符号；
- 数值输入框；
- 单位；
- 说明；
- 合理范围；
- 是否必填；
- 默认值来源；
- 错误提示。

## 11.2 输入组件

基础输入组件：

- NumberInput；
- UnitInput；
- Select；
- Toggle；
- Radio；
- FormulaInput；
- FileInput；
- ExampleLoader。

## 11.3 输入规则

禁止：

- 只用placeholder作为标签；
- 单位与输入框分离过远；
- 不限制异常值；
- 把0当作未输入；
- 输入错误只显示红框；
- 自动修改用户输入但不提示；
- 同一工具混用不同单位体系。

## 11.4 示例数据

每个工具应提供：

- 教学示例；
- 典型工程示例；
- 空白输入；
- 恢复默认。

示例数据加载后必须明确提示：

> 当前为示例数据，不代表实际项目参数。

## 11.5 高级参数

基础工具的高级参数采用折叠区：

- 小数位；
- 单位体系；
- 修正系数；
- 数据有效性；
- 输出选项。

普通用户不应被高级参数干扰。

# 12. 计算按钮与触发逻辑

## 12.1 触发方式

支持：

- 点击计算；
- Ctrl+Enter；
- 表单提交；
- 可选实时计算。

首个干固体量工具建议：

> 默认点击计算，不启用每次输入立即计算。

原因：

- 避免频繁请求；
- 减少输入中间状态干扰；
- 便于记录计算版本；
- 保证结果可追溯。

## 12.2 计算前检查

必须检查：

- 必填项；
- 数值类型；
- 合理范围；
- 单位；
- 数据有效性；
- 权限；
- 当前工具版本。

## 12.3 计算状态

- 未计算；
- 校验中；
- 计算中；
- 成功；
- 警告；
- 失败；
- 权限不足。

# 13. 结果面板规范

## 13.1 结果层级

结果按以下层级展示：

1. 核心结果；
2. 相关结果；
3. 数据有效性；
4. 诊断；
5. 计算过程；
6. 风险与限制。

## 13.2 核心结果卡片

每张核心结果卡片包含：

- 结果名称；
- 数值；
- 单位；
- 状态；
- 说明；
- 复制按钮。

数值格式：

- 保留合理小数位；
- 单位统一；
- 千位分隔按需要；
- 不显示无意义的8位小数；
- 0必须正常显示；
- 无数据使用“—”而不是0。

## 13.3 结果颜色

颜色只表示状态，不表示数值大小。

- 正常：绿色；
- 提示：蓝色；
- 警告：橙色；
- 无效：红色；
- 未计算：灰色。

## 13.4 结果摘要

结果区顶部应提供一句话摘要。

示例：

> 当前矿浆质量流量为163.35 t/h，按42.00%固体质量浓度计算，干固体处理量为68.61 t/h。

# 14. 计算过程规范

计算过程必须可展开。

内容：

- 输入参数；
- 单位转换；
- 公式；
- 代入；
- 中间值；
- 最终值；
- 假设；
- 公式版本。

示例：

```text
矿浆质量流量
= 矿浆体积流量 × 矿浆密度
= 118.37 m³/h × 1.38 t/m³
= 163.35 t/h

干固体量
= 矿浆质量流量 × 固体质量分数
= 163.35 t/h × 42.00%
= 68.61 t/h
```

不得只显示最终结果。

## 16.2 工具用途

用于根据矿浆体积流量、矿浆密度和固体质量浓度计算：

- 矿浆质量流量；
- 干固体量；
- 水量；
- 固体体积分数（可选）；
- 数据有效性。

## 16.3 输入参数

### 矿浆体积流量

字段：

```text
slurry_volume_flow
```

单位：

```text
m³/h
L/s
```

默认单位：

```text
m³/h
```

校验：

- 必填；
- 大于等于0；
- 建议范围0～100000 m³/h；
- 超出建议范围显示警告，不一定阻止计算。

### 矿浆密度

字段：

```text
slurry_density
```

单位：

```text
t/m³
kg/L
kg/m³
```

默认单位：

```text
t/m³
```

校验：

- 必填；
- 大于0；
- 建议范围1.0～3.5 t/m³；
- 小于水密度或过高时显示警告。

### 固体质量浓度

字段：

```text
solids_mass_fraction
```

单位：

```text
%
fraction
```

默认单位：

```text
%
```

校验：

- 必填；
- 0～100%；
- 0是有效值；
- 大于100%禁止计算。

### 固体密度（可选）

字段：

```text
solids_density
```

单位：

```text
t/m³
```

用途：

- 计算固体体积分数；
- 进行矿浆密度一致性检查。

默认：

```text
2.70 t/m³
```

## 16.4 输出参数

### 矿浆质量流量

```text
slurry_mass_flow_t_h
```

单位：

```text
t/h
```

公式：

```text
Qm = Qv × ρslurry
```

### 干固体量

```text
dry_solids_rate_t_h
```

单位：

```text
t/h
```

公式：

```text
Qs = Qm × Cw
```

### 水量

```text
water_mass_flow_t_h
```

单位：

```text
t/h
```

公式：

```text
Qw = Qm × (1 - Cw)
```

可选近似体积流量：

```text
water_volume_flow_m3_h ≈ water_mass_flow_t_h
```

必须明确这是按水密度1.0 t/m³的近似。

## 16.5 一致性检查

当用户提供固体密度时，可以进行：

- 计算理论矿浆密度；
- 对比输入矿浆密度；
- 显示偏差；
- 标记数据存疑。

不得自动替换用户密度。

## 16.6 示例数据

```text

```

示例结果：


# 39. 结论

```text
所有基础工具

```
