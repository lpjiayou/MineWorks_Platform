# 1. 任务目标

本阶段不追求一次完成所有高级组件，重点建立：

```text

→ 主题系统
→ 基础组件
→ 工程领域组件
→ 工具页面模式
→ Storybook
→ 自动测试
```

首个验收对象：

```text

```

# 16. 开发红线

1. 不在页面重新写相同组件；
2. 不在组件中直接写业务API；
3. 不在组件中散落单位转换；
4. 不把0当空值；
5. 不把null显示成0；
6. 不只靠颜色表达状态；
7. 不跳过深色主题；
8. 不跳过手机布局；
9. 不暴露第三方默认样式；
10. 不在FormulaBlock渲染不安全HTML；
11. 不让PermissionGate替代后端权限；
12. 不在ErrorState显示后端堆栈；
13. 不在Modal缺少焦点锁定；
14. 不在Loading时允许重复提交；
15. 不用Emoji作为正式图标；
