## 2. 原型计算公式

### 矿浆质量流量

```text
Qm = Qv × ρm
```

### 干固体量

```text
Qs = Qm × Cw
```

### 水量

```text
Qw = Qm × (1 − Cw)
```

### 理论矿浆密度

```text
ρth = 1 / (Cw/ρs + (1−Cw)/ρw)
```

其中水密度默认采用：

```text
ρw = 1.0 t/m³
```

## 3. 默认示例

输入：

```text
矿浆体积流量：118.37 m³/h
矿浆密度：1.38 t/m³
固体质量浓度：42.00%
固体密度：2.70 t/m³
```

核心结果约为：

```text
矿浆质量流量：163.35 t/h
干固体量：68.61 t/h
水量：94.74 t/h
```

页面中的结果由输入实时计算，不是硬编码结果。

## 5. 数据有效性规则

原型采用以下演示规则：

- 无警告：`VALID`；
- 存在一般范围警告：`CAUTION`；
- 输入矿浆密度与理论密度偏差超过10%：`INCONSISTENT`。

正式系统需由专业审核确认阈值，并在Python计算核心中统一实现。

## 7. 生产实现边界

正式系统中禁止把公式保留在React页面。

推荐数据链：

```text
Next.js表单
→ FastAPI请求校验
→ mining_core统一单位转换与计算
→ 返回结果、步骤、警告和有效性
→ 前端渲染
→ 保存计算记录
```

每条计算记录必须包含：

- 工具ID；
- 工具版本；
- 输入原值和单位；
- 标准化输入；
- 结果；
- 公式步骤；
- 警告；
- 有效性；
- 用户；
- 项目；
- 时间。
