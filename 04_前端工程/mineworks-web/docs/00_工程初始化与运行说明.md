## Windows运行步骤

```powershell
cd D:\Codex使用\矿业智工平台\04_前端工程\mineworks-web
node -v
npm -v
npm install
copy .env.example .env.local
npm run dev
```

## 访问地址

```text
前端：http://localhost:3000

```
