# 前端工程目录结构说明

```text
mineworks-web/
├─ .storybook/              Storybook配置
├─ docs/                    项目说明
├─ public/brand/            Logo和品牌资源
├─ src/
│  ├─ app/                  Next.js页面与布局
│  ├─ components/
│  │  ├─ brand/             品牌组件
│  │  ├─ data-display/      数值和卡片
│  │  ├─ feedback/          状态与提示
│  │  ├─ forms/             字段和单位输入
│  │  ├─ layout/            Panel和Header
│  │  ├─ primitives/        Button和IconButton
│  │  ├─ providers/         ThemeProvider
│  │  ├─ theme/             ThemeToggle
│  │  └─ tools/             ToolCard
│  ├─ design-system/        设计令牌
│  ├─ lib/                  单位、格式和工具函数
│  ├─ test/                 测试初始化
│  └─ types/                共享类型
├─ package.json
├─ tsconfig.json
├─ eslint.config.mjs
└─ vitest.config.ts
```

## 依赖边界

```text
页面 → 页面模式/组件 → 领域组件 → 基础组件 → 设计令牌
```

禁止反向依赖：基础组件不得导入具体业务页面或API。
