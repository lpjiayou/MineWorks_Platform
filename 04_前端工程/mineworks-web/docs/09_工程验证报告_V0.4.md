## 工程边界

- 权限组件不能替代后端权限校验；
- 导出菜单只负责前端入口和状态，正式文件必须由后端或受控导出服务生成；
- FormulaBlock只显示安全纯文本；
- ProjectPicker不直接调用项目API；
- FilterBar只发出筛选状态，URL同步和数据请求由页面层负责；
- 计算步骤必须最终由FastAPI与mining_core返回。

## 验收结论

MineWorks UI V0.4满足P0领域组件第三批交付要求，可进入工具中心真实页面模式和基础工具页面模式开发。
