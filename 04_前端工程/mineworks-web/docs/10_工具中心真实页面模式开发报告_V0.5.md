# 工具中心真实页面模式开发报告 V0.5

> 项目：矿业智工平台  
> 前端版本：V0.5.0  
> 编制日期：2026-07-14  
> 建议保存目录：`D:\Codex使用\矿业智工平台\04_前端工程\mineworks-web\docs\`

---

## 1. 本阶段目标

本阶段将工具中心从静态视觉原型转为可运行的Next.js真实页面模式，建立后续持续增加矿业工程工具所需的数据、导航、状态和用户偏好基础。

## 2. 新增路由

```text
/tools
/tools/[slug]
```

`/tools`为工具中心真实页面。`/tools/[slug]`为工具说明与权限预览页，保证所有工具卡片均有可访问目标，不出现404。

## 3. 工具数据模型

新增统一`ToolDefinition`，包含：

- 工具ID与slug；
- 名称、说明和标签；
- 专业分类；
- 工具类型；
- 免费、专业、团队与企业权益；
- 审核状态；
- 可用、预览与规划状态；
- 版本与更新时间；
- 图标名称；
- 推荐标记与排序权重。

当前首批目录共24项，覆盖：

- 选矿工程；
- 采矿工程；
- 自动化；
- 电气工程；
- 设备工程；
- 土建工程；
- 通用工程。

## 4. 分类导航

新增`CategoryNavigation`组件：

- 全部工具；
- 选矿工程；
- 采矿工程；
- 自动化；
- 电气工程；
- 设备工程；
- 土建工程；
- 通用工程。

分类显示工具数量，桌面为网格，平板和手机为横向滚动。

## 5. URL状态

工具中心以下状态写入URL：

```text
q
 discipline
 category
 access
 status
 sort
 view
 favorites
```

支持：

- 刷新后恢复；
- 复制链接分享当前筛选；
- 浏览器前进和后退；
- 卡片和列表视图恢复；
- 多选条件逗号编码。

## 6. 收藏与最近使用

使用浏览器本地存储：

```text
mineworks.toolFavorites.v1
mineworks.recentTools.v1
```

功能：

- 收藏和取消收藏；
- 仅看收藏；
- 最近使用最多8项；
- 重复打开自动移到最前；
- 详情页直接访问也记录最近使用；
- 不保存任何工程输入参数。

正式登录系统完成后，可将该接口替换为账户云同步。

## 7. 免费与会员工具

工具卡片统一显示：

- 免费；
- 专业会员；
- 团队；
- 企业；
- 已验证；
- 技术审核中；
- 教学示例；
- 草稿或规划中。

当前演示身份为免费用户：

- 免费工具显示“立即使用”；
- 会员工具显示“查看权益”；
- 规划工具显示“查看规划”；
- 详情页使用`PermissionGate`展示价值和升级说明。

前端状态不替代后端权限校验。

## 8. ToolCard增强

`ToolCard`新增：

- 卡片与列表两种视图；
- 版本和更新时间；
- 规划状态；
- 锁定状态；
- 收藏回调；
- 打开回调；
- 免费、会员和规划操作文案；
- 手机列表布局。

## 9. 页面视觉

工具中心包含：

- 品牌Hero；
- 当前访问身份；
- 工具总数、已验证、重点推荐和收藏指标；
- 专业分类；

- 搜索、筛选、排序和视图；

- 空结果；
- 数据与权限边界说明。

响应式重点覆盖1366×768、平板和390px手机。

## 12. 边界

本阶段没有：

- 用户登录；
- 云端收藏；
- 后端工具目录；
- 正式会员订单；
- FastAPI工具计算；
- mining_core正式算法；
- 项目记录保存。

这些能力将在后续后端与账户阶段接入。
