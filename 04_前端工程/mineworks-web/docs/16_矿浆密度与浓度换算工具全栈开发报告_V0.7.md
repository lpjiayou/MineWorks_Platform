## 公式边界

采用固液两相、体积可加模型：

```text
ρm = 1 / [Cw / ρs + (1 − Cw) / ρl]
Cv = Cw × ρm / ρs
Cv = (ρm − ρl) / (ρs − ρl)
ρm = Cv × ρs + (1 − Cv) × ρl
Cw = Cv × ρs / ρm
```

不适用于未经修正的含气、泡沫、多相和显著体积收缩工况。
