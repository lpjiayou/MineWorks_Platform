# 用户身份、项目成员、团队权限与服务端授权体系开发报告 V0.9

> 项目：矿业智工平台  
> 工程：mineworks-web  
> 版本：V0.9.0  
> 日期：2026-07-14

## 1. 阶段目标

本阶段将V0.8的本地项目与统一计算历史升级为有明确身份和权限边界的协作系统：

```text
用户身份
→ 多团队工作区
→ 团队角色
→ 项目成员角色
→ 服务端授权
→ 记录归属
→ 操作审计
```

## 2. 已完成能力

### 用户身份

- 邮箱注册；
- 密码登录；
- 当前身份查询；
- 会话退出与服务端撤销；
- 账户状态和套餐字段；
- 多团队切换；
- 首位用户接管V0.8无归属数据。

### 密码与会话

- PBKDF2-HMAC-SHA256；
- 每个密码独立随机盐；
- 310000次迭代；
- 密码强度检查；
- 48字节随机Bearer令牌；
- 数据库只保存SHA-256令牌摘要；
- 会话有效期和撤销时间；
- 最近使用时间、User-Agent与IP字段。

### 团队角色

```text
owner
admin
engineer
viewer
```

提供团队成员列表、直接添加已注册用户、角色修改、成员移除、邀请口令、邀请接受和审计记录。

### 项目角色

```text
owner
manager
editor
viewer
```

项目支持：

- 团队可见；
- 私有项目；
- 项目成员；
- 项目角色；
- 项目成员管理；
- 项目数据隔离。

### 服务端授权

以下接口不再相信前端按钮状态，全部在FastAPI服务端验证：

- 项目创建、读取和成员管理；
- 统一计算历史读取、保存、更新和删除；
- 结果复用；
- 团队成员和邀请；
- 团队审计日志。

请求上下文：

```text
Authorization: Bearer <session-token>
X-Team-Id: <active-team-id>
```

## 3. 权限解析

### 团队权限

- `viewer`：读取团队、项目和记录；
- `engineer`：增加项目和计算记录写入；
- `admin`：成员、项目和审计管理；
- `owner`：完整团队管理和所有者授权。

### 项目权限

- 团队所有者/管理员自动获得项目管理权限；
- 项目所有者拥有最高项目权限；
- 私有项目仅所有者、项目成员和团队管理员可见；
- 团队可见项目允许团队成员按团队角色读取或编辑。

## 6. 安全边界

V0.9适用于本地开发、内部试用和授权模型验证。正式公网部署必须继续完成：

1. HTTPS；
2. HttpOnly、Secure、SameSite Cookie或企业OIDC；
3. CSRF防护；
4. 登录限流与异常检测；
5. 邮箱验证和密码重置；
6. MFA；
7. 邀请邮件；
8. 密钥管理与轮换；
9. PostgreSQL迁移；
10. 审计日志留存和不可篡改策略。

不得将当前localStorage Bearer实现直接视为最终公网安全方案。
