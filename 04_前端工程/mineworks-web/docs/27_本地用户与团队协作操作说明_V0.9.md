# 本地用户与团队协作操作说明 V0.9

## 首个用户

1. 启动FastAPI和Next.js；
2. 打开`http://127.0.0.1:3000/login`；
3. 点击注册；
4. 密码至少10位并含大小写字母和数字；
5. 首位用户自动成为初始团队所有者；
6. V0.8已有本地项目和计算记录自动归属首位用户。

## 添加第二个用户

1. 第二个用户先注册自己的账户；
2. 所有者打开`/team`；
3. 输入第二个用户邮箱；
4. 可选择“直接加入”，也可生成一次性邀请口令；
5. 生成邀请时，把口令安全发送给受邀用户；
6. 受邀用户登录后打开`/account`，在“接受团队邀请”中粘贴口令并确认。

## 团队角色

- 所有者：完整团队权限；
- 管理员：成员、项目和审计管理；
- 工程师：创建项目和计算记录；
- 查看者：只读。

## 项目成员

打开`/projects/{projectId}`管理项目成员。用户必须先加入项目所属团队，才能被加入项目。

## 数据备份

用户、会话、团队、项目和计算历史均位于：

```text
backend/data/mineworks.db
```

备份工程时必须同时备份该数据库。
