# 会员套餐、功能权益、使用配额与订阅计费基础架构开发报告 V1.0

> 项目：矿业智工平台  
> 工程：mineworks-web  
> 版本：V1.0.0  
> 编制日期：2026-07-14

## 一、阶段目标

本阶段把V0.9已经建立的用户身份、团队角色和服务端授权继续扩展为可商业化的基础数据链：

```text
用户/团队身份
→ 有效套餐
→ 功能权益
→ 使用配额
→ 订单
→ 订阅
→ 服务端授权与用量记录
```

当前版本用于本地开发、产品验证和商业模式设计，不连接真实支付机构。

## 二、完成内容

### 1. 四级套餐目录

```text
free          免费版
professional  专业版
team          团队版
enterprise    企业版
```

套餐目录由后端统一维护，前端通过`GET /api/v1/plans`读取，不在页面中复制套餐规则。

### 2. 服务端有效套餐解析

有效套餐同时考虑：

- 用户个人套餐；
- 当前活动团队套餐；
- 有效订阅记录；
- 套餐等级高低。

解析结果包含：

```text
user_plan
team_plan
effective_plan
plan_source
```

### 3. 功能权益代码

首批功能代码：

```text
tool.basic.calculate
history.save
project.workspace
export.markdown
export.json
analysis.advanced
calculation.batch
export.excel
export.word
team.collaboration
team.audit
template.shared
api.access
sso.enterprise
support.priority
```

前端的`PermissionGate`用于展示；FastAPI通过`assert_feature`和`require_feature`进行最终校验。

### 4. 使用配额

月度配额：

```text
calculations.monthly
exports.monthly
```

总量配额：

```text
projects.total
records.total
teams.total
team_members.total
```

月度配额按UTC自然月统计；项目、记录、团队和成员配额直接读取当前数据库实际数量。

### 5. 用量计数与事件

新增：

```text
usage_counters
usage_events
```

已登录用户调用两个正式计算工具时，会在计算成功后记录一次`calculations.monthly`。游客仍可以使用免费基础计算，但不生成账户用量记录。

### 6. 本地演示订单与订阅

新增：

```text
billing_orders
subscriptions
```

本地开发环境支持：

1. 创建个人专业版订单；
2. 创建团队版订单；
3. 模拟支付成功；
4. 激活订阅；
5. 更新用户或团队套餐；
6. 刷新前端身份和权益。

企业版必须进入人工报价，不能通过本地模拟直接开通。

### 7. 配额执行位置

已接入：

- 干固体量计算；
- 矿浆密度与浓度换算；
- 创建项目；
- 保存计算记录；
- 创建团队；
- 添加或邀请团队成员。

超限统一返回：

```text
HTTP 429
code = QUOTA_EXCEEDED
```

无功能权益统一返回：

```text
HTTP 403
code = FEATURE_NOT_ENTITLED
```

## 四、数据库变更

新增数据表：

```text
subscriptions
billing_orders
usage_counters
usage_events
```

原有`users.plan`和`teams.plan`继续保留，作为当前套餐的快速读取字段。订阅激活时会同步更新对应字段。

V0.9及更早版本创建的团队不会被自动降级；V1.0以后新建的团队默认是免费版。

## 五、关键安全边界

- 订单和订阅状态只能由服务端写入；
- 个人订单只能由订单本人操作；
- 团队订单只能由当前团队所有者或管理员操作；
- 前端隐藏按钮不等于授权；
- 套餐和配额全部由后端重新判断；
- 用量在计算成功后写入，失败请求不消耗额度；
- 本地支付模拟默认只允许开发环境使用；
- 企业版不能直接模拟开通。
