## 三、套餐作用域

### 个人专业版

作用于用户本人，适合单人使用高级工具和专业导出。

### 团队版

作用于当前团队工作区，团队成员共享功能权益和月度用量池。

### 企业版

作用于企业组织，额度和功能由合同及部署范围决定。

## 四、用量归属规则

```text
团队套餐等级 >= 个人套餐等级且团队套餐高于免费
→ 用量计入团队

否则
→ 用量计入个人
```

## 五、超限处理

```text
功能未开通：HTTP 403 / FEATURE_NOT_ENTITLED
配额已用尽：HTTP 429 / QUOTA_EXCEEDED
```

不得在前端静默绕过服务端限制。
