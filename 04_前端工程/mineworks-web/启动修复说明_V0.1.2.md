# 矿业智工平台前端启动修复补丁 V0.1.2

## 根因

上一版批处理文件使用了UTF-8 BOM和中文命令文本，Windows `cmd.exe`发生解析错位。

截图中的典型错误：

```text
'有' is not recognized as an internal or external command
'ho' is not recognized as an internal or external command
'�╗┐@echo' is not recognized as an internal or external command
```

因此旧脚本没有真正完成依赖安装和服务启动。

本补丁中的可执行脚本采用：

```text
纯ASCII字符
无UTF-8 BOM
Windows CRLF换行
无中文命令文本
```

## 保存位置

将压缩包内全部 `.cmd` 文件复制到：

```text
D:\Codex使用\矿业智工平台\04_前端工程\mineworks-web\
```

必须与 `package.json` 位于同一级目录。

## 正确执行顺序

### 1. 安装依赖

双击：

```text
01_INSTALL_DEPENDENCIES.cmd
```

等待出现：

```text
INSTALL_OK
```

安装完成后，项目根目录应出现：

```text
node_modules
```

### 2. 启动Next.js

双击：

```text
02_START_NEXTJS.cmd
```

保持窗口打开，等待Next.js显示 `Ready`，然后打开：

```text
http://127.0.0.1:3000
```

设计系统页面：

```text
http://127.0.0.1:3000/design-system
```

### 3. 启动Storybook

另外双击：

```text
03_START_STORYBOOK_6007.cmd
```

保持第二个窗口打开，等待Storybook显示 `Local`，然后打开：

```text
http://127.0.0.1:6007
```

本机6006端口已有其他程序响应404，所以本补丁固定使用6007。

## 诊断

运行：

```text
00_CHECK_ENV.cmd
```

可以检查Node、npm、node_modules和端口状态。

## 项目验证

依赖安装完成后运行：

```text
04_VERIFY_PROJECT.cmd
```

依次执行：

```text
npm run lint
npm run typecheck
npm run test
npm run build
```

## 注意

Next.js和Storybook是两个长期运行进程：

```text
窗口1：Next.js，端口3000
窗口2：Storybook，端口6007
```

关闭对应窗口后，对应网站立即停止。
