# 共享计算核心规划目录规则

本文件适用于 `06_共享计算核心`，并补充项目根目录 `AGENTS.md`。

## 当前阶段

该目录是未来独立 `mining_core` 的目标规划目录。当前正式实现仍位于：

```text
04_前端工程\mineworks-web\backend\mining_core
```

未经用户批准，不得手工移动、复制后删除、改名或切换现有 `backend\mining_core`。在独立化任务正式启动前，本目录优先保存盘点、差异审计、包结构、版本、迁移、回退和验收方案。

## 核心边界

1. PySide6 桌面版与 FastAPI 必须安装并调用同一版本核心。
2. 禁止两端分别维护同一项正式工程公式。
3. 核心不得依赖 PySide6、Qt、React、Next.js、浏览器或界面状态。
4. 核心统一管理公式、单位、契约、校验、警告、错误代码、有效性、计算步骤和版本。
5. `0` 是有效数值，`null` 是无数据，`NaN` 是计算错误。
6. 所有正式工具返回或可追溯到 `tool_version`、`formula_version`、`core_version`、`contract_version`。

## 独立化前置条件

1. 完成桌面版工具和公式盘点；
2. 完成桌面与网页公式、单位、字段、默认参数和精度差异审计；
3. 经专业审核确认唯一正式公式；
4. 建立统一 fixtures 和已知手算样例；
5. 形成包结构、依赖、版本、发布、迁移和回退方案；
6. 明确历史结果兼容与旧公式保留策略；
7. 获得用户对实施范围的明确确认。

## 验收要求

同一组基准输入必须满足：

```text
共享核心直接结果
= PySide6 适配层结果
= FastAPI 接口结果
= 网页显示结果
```

仅允许有书面说明的显示精度差异。公式、单位、默认参数、警告、有效性和实际结果不得分叉。

任何公式变更都必须包含来源、审核人、版本升级、变更日志、测试、迁移说明和双端验证报告。未经授权，本目录不得用于直接改写正式公式。
