## 1. 说明

本清单只记录版本差异，不修改任何现有版本值。应用代码版本、部署显示版本、API 版本、文档版本和工具/公式版本不是同一概念，后续必须逐项评估，禁止对 `1.1.0` 做全项目批量替换。

`package.json` 与 `backend\pyproject.toml` 当前均为 `1.1.1`，是本轮判断应用代码基线的主要依据。

## 3. 不属于平台版本差异的匹配项

`package-lock.json` 中的多个 `1.1.0` 是第三方依赖版本或 Node.js semver 范围，不是矿业智工平台版本。本轮不调整依赖或锁文件。

`.env.local` 和 `backend\.env` 属于本地敏感配置，已从 Git 排除；本轮没有在报告中输出其值，也不以本地值作为可提交版本基线。

## 4. 后续处理原则

1. 应在独立版本整理任务中同步应用、API、示例配置、Docker 和文档版本。
2. `backend\openapi.json` 应由确认后的 API 定义重新生成并复核。
3. 工具版本、公式版本、核心版本和契约版本必须独立管理，不得与平台版本机械绑定。
4. 本轮没有修改上述任何现有文件或版本值。
